HTML kopieren

Hier startet kein Spiel. Du kopierst hier nur die komplette HTML und die Firebase-Regeln, um sie in dein Firebase-Projekt einzufügen.

So geht’s

  1. Warte, bis bei der Datei „Bereit“ steht, und tippe dann auf Kopieren.
  2. Spiel (Firebase Hosting): In deinem Projekt den ganzen Inhalt von public/index.html löschen, den kopierten Text einfügen, speichern und firebase deploy ausführen.
  3. Regeln: Firebase-Konsole → Firestore Database bzw. Realtime Database → Tab Regeln → alles löschen, einfügen, Veröffentlichen.
  4. firebase.json kommt in den Hauptordner deines Firebase-Projekts (neben den Ordner public).

Ausführliche Anleitung: firebase/ANLEITUNG.md

Die Spiel-Dateien sind ca. 20 MB groß. Manche Handys (vor allem Android) schaffen so viel Text nicht in der Zwischenablage. Klappt das Einfügen nicht, nimm Herunterladen und lade die Datei bei Firebase hoch.
